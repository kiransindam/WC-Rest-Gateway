Adds a configurable eco-friendly packaging fee to the WooCommerce checkout.

== Description ==

Encourage sustainable practices by adding a small "Eco-Friendly Packaging" fee to your customers' checkout. 

**Features:**
* Fully configurable from WooCommerce Settings.
* Enable/Disable the fee with one click.
* Customizable fee title and amount.
* 100% compatible with WooCommerce High-Performance Order Storage (HPOS).
* Follows strict WordPress and WooCommerce coding standards.

== Installation ==

1. Upload the `wc-eco-fee` folder to the `/wp-content/plugins/` directory, or install via the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to **WooCommerce > Settings > Eco-Friendly Fee** to configure your fee.
